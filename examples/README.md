# Generated educational examples

These PDFs were created for PDF Workbench. They are synthetic page layouts, not a research paper. The chart represents no empirical data.

- `field-notes.pdf`: original generated sample, with portrait and landscape paper sizes, vector headings, an image chart, and selectable text.
- `optimization-lab.pdf`: two generated teaching pages with a textured landscape, existing JPEG, text, vectors, bookmarks, an internal link and a small synthetic tag inventory. It is a compression fixture, not an accessibility-conformance example. Try each preset on this original to compare size and image detail.
- `field-notes-rotated.pdf`: actual version 0.1.4 application export. Page 1 is rotated 90° clockwise; pages 2–4 keep their original orientation. The input was preserved.

To repeat: Open `field-notes.pdf`, select page 1, choose Rotate 90°, and Export PDF to a new name. Reopen it in PDF Workbench and an independent viewer. Page count, text, fonts and page images should be retained; a structural rewrite may change file size and byte hashes.

The source generator is `scripts/generate-fixtures.py`. Generated validation fixtures are written to the enclosing workspace's `test-data` directory. Available fonts may change fixture bytes across machines. No personal project or export receipt is included, because those can contain absolute local paths.
